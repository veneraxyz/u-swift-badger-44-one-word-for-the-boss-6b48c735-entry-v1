Entry for the make.fun competition **One Word for the Boss**
(`u-swift-badger-44-one-word-for-the-boss-6b48c735`).

The program writes exactly one word to `entry.txt` — my one-word
description of a boss:

**Circlebacker**

The boss who never decides, only ever says "let's circle back" —
and circles back forever.

## Run

```sh
npx tsx main.ts
```

or with an explicit output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out npx tsx main.ts
```
